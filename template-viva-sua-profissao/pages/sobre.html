Sobre o Projeto & Arquitetura do Site

Documentação do portal sobre Desenvolvimento Front-End; volte para a página inicial do guia quando quiser revisar o resumo.

Estrutura de Navegação (Mapa do Site)

Organização das páginas HTML do portal:

  • index.html — Visão geral da profissão Front-End e chamadas principais
  • pages/habilidades.html — Competências técnicas, comportamentais e trilha
  • pages/materiais.html — Banner, esboço de landing page e e-book
  • pages/sobre.html — Arquitetura, hospedagem e créditos

Por que GitHub Pages? (Site Estático)

Este portal foi desenvolvido com HTML5 e CSS3 como um site estático, hospedado gratuitamente via GitHub Pages.

Diferente de sistemas em PHP ou WordPress, ele não exige processamento no servidor nem banco de dados para exibir páginas informativas, garantindo carregamento rápido e versionamento via Git/GitHub.
